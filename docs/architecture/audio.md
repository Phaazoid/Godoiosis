## AudioDirector

`audio/` — the only place a sound is played ([#136](https://github.com/Phaazoid/Godoiosis/issues/136), 2026-09-11). **`AudioDirector`** is a game collaborator on the `DevController`/`MissionLog` pattern and **owns no rule**: it consumes #887's `volley_struck` rather than inventing a trigger, so *one blast is one moment* is the project's own granularity and not a choice made here, and whether a cue plays is read off authored fields (`AttackData.heals` / `deals_no_damage`, **null-tolerant** — `fired_attack` is null for bare fists, which damage). **WHICH cue is the ATTACK's own answer since slice 2 — `AttackData.sound`, on the shared base rather than on `WeaponData`, which is [#485](https://github.com/Phaazoid/Godoiosis/issues/485)'s ruling one field along**: per family every attack a weapon owned would sound alike, a mod-granted attack could bring no voice of its own, and an element's sound would need a second mechanism since a carving has no `WeaponData` to hang off. No fallback on the template — a family's sound IS its main attack's. `cue_for` LAYERS over `plays_impact`, so **the damage gate governs the DEFAULT alone**: a generic punch is wrong on a heal, an authored heal chime is not. The Attack Editor draws no row for it, which is `icon`'s own long-standing state rather than a new gap — `DevWidgets._add_resource_swapper` builds its picker from the global CLASS list, so an engine-typed resource offers no candidates and authoring happens in Godot's inspector.

**NOT a `battle3d` node**, unlike `ArcLightning` which consumes the same signal: a bolt is something the diorama draws, a sound is not view-specific, and hanging this off the 3D host would leave a `Main.tscn` launch silent. **`PROCESS_MODE_ALWAYS`, and it is correctness**: `ModalLock` disables the Game node, and a DISABLED parent STOPS an `AudioStreamPlayer`'s stream (measured headless 2026-09-11 — INHERIT under DISABLED reads `playing=false`, ALWAYS reads true), so a director on INHERIT would cut a hit sound off mid-blow when the pause menu opened; the pool inherits ALWAYS from it. **FLAT, not positional** (dev, 2026-09-11) — no listener, no attenuation, no coupling to the #410 camera arc; going positional later changes the play site, not the design. `default_bus_layout.tres` (Master + SFX + Music, Godot's default path so `project.godot` is untouched) is GENERATED through `AudioServer.generate_bus_layout()` + `ResourceSaver.save()`, never hand-authored — the dirty-tree rule — and its generator is deliberately not committed, on the `LookPresets` precedent.

**A headless suite cannot hear anything**; what it can see is that a player was told to play, which is why `tests/audio/test_audio_director.gd` drives a real pass and asserts on `playing`, and why whether a cue SOUNDS right is claimed nowhere in it. **How loud a bus is also lives here and is ONE answer for every bus since slice 3** — `BUS_FOR_SETTING` maps a `PlayerSettings` LEVEL row to a bus name and `_process` walks it, so a third bus is one line rather than a second copy of the reconcile, each name read from the director that owns that bus rather than spelled twice.

## MusicDirector

**...and `MusicDirector` is the one place a TRACK is chosen ([#136](https://github.com/Phaazoid/Godoiosis/issues/136) slice 3, 2026-09-11) — a SIBLING of `AudioDirector`, never an extension of it.** That file answers *what did this blow sound like* and its header is explicit that it owns no rule; a score is the opposite shape (one at a time, looping, persisting across a mission) and it DOES own a rule — which track belongs to which phase — so folding it in would make the other file's own central claim false. Two doors, two questions; it never touches `AudioServer` (that is the bus table above) and `PROCESS_MODE_ALWAYS` for `AudioDirector`'s two measured reasons.

**A RECONCILE, NOT AN EVENT**: it asks every frame what should be playing and swaps if that differs, which is the project's own idiom (`PlayerSettings` has no changed signal, `UnitMirror` is a per-frame reconcile), so `TurnManager.turn_started` needs no listener and the state cannot drift from the truth because it IS a read of the truth. The rule is two existing public reads and nothing re-derived: `MissionController.mission_select_is_up()` → the title theme, else `Team.is_enemy(Team.Faction.PLAYER, turn_manager.active_faction())` → *Enemy Approaching*, else *Battlefield*. **WHOSE SIDE, NEVER WHO IS IN CONTROL (dev ruling, 2026-09-11).** The ask was *"swap to the enemy approaches during AI turns"* and in this game the enemy IS the computer, so the two spellings coincide — which is what makes the wrong one easy to write. They part both ways: **hotseat (ENEMY with AI off) is how the dev tests** (`BoardLint._check_ai_factions` exists for that state), where a control read plays the PLAYER's track through the enemy's whole turn; and `ALLY` is a real `Team.Faction`, so an AI-controlled ally would announce itself as the enemy. NOT `GameState.AI_TURN` either — that is the input lock, false during the hand-off beat and the mission banner, exactly when the music should already be crossing.

**Any phase neither read sees gets the battle track**, which is deliberate: the pre-mission screen and the mission-end banner are both that case today. **ONE PLAYER PER TRACK, never a pool**, because a pool cannot survive a swap arriving MID-FADE (a computer turn can end inside the fade, and the only free player is the one still sounding the outgoing track, so recycling it cuts that track dead at half volume) — per track a swap is only ever *this one's level rises, the others' fall, from wherever they ARE*, so a reversed fade is the ordinary case and nothing is ever cut. `CROSSFADE_SECONDS` is a `GameKnobs` row on its own Audio tab and **is not polish**: the swap fires twice a round, and a hard cut forty times a mission is what would make a score read as worse than silence; zero means INSTANT, never a division.

**`resumes` is PER TRACK because the turns are not symmetric** — a player turn is minutes and a computer turn is seconds, so *Battlefield* picks up where it left off (or a 1:09 loop is the same first fifteen seconds all mission) while *Enemy Approaching* restarts (resuming it in ten-second fragments means never hearing a phrase, where restarting plays the hook every time). Files are named for the WORK, not the role (`battlefield.mp3`, not `battle.mp3`) — the opposite of the SFX convention, because a track is a composition with a title `CREDITS.md` has to name, so the role lives in the table and the file keeps the name Simeon gave it.

**An `AudioStreamMP3` does not loop unless its `.import` says so** (`loop=true` under `[params]`, verified by reading `stream.loop` back rather than trusting the key name — a wrong key is ignored in silence and the failure mode is a track that plays once); MP3 encoder padding means the loop point carries a ~26ms gap, and the fix for that would be an OGG transcode rather than code. Three of the five recovered tracks ship; Journey and Boss Battle 1 arrive with the per-mission field ([#918](https://github.com/Phaazoid/Godoiosis/issues/918)), which is deliberately NOT built here — `ScenarioData` IS the save snapshot, so any save predating such a field loads it null and falls through to exactly these constants, which are therefore needed either way.
